# GrowWithin AI

GrowWithin AI is an AI-powered workforce development application that helps employees discover internal positions and projects that match their skills. It also identifies skill gaps and creates personalized 30/60/90-day development plans.

## Planned Technology Stack

- React
- Java Spring Boot
- PostgreSQL
- Docker
- OpenAI API
- Postman
